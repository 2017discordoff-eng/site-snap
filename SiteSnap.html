Get started in 30 seconds

Terminal 
# Install deps
pip install playwright beautifulsoup4 requests
playwright install chromium

# Clone a site (Playwright mode — full JS rendering)
python site_cloner.py https://example.com

# Static mode (no browser, faster)
python site_cloner.py https://example.com --no-js

# Custom output path
python site_cloner.py https://example.com -o my_clone.html
SiteSnap Runs locally — your data never leaves your machine.
